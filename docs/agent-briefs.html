What changed in contract v2 (re-paste it into your agent):

  1. CAR-DEF is a glossary table. Each term is its own Article (CAR-DEF|Apron (APN)): title is the term, text is the definition, and extra.kind = "glossary_term". P3 must read these directly, with no regex.
  2. Articles may carry extra (e.g. icao_source).
  3. New regulation names and display formats: CAR-ADR · §4.7, CAR-AGA-PART-ADR · ADR.OR.C.020.
  4. Real-text rules: PDF word splits, mid-sentence line breaks, curly-quote definitions, and CAR-DEF's precedence rule.
  5. Mock data: the CAR-DEF entries are now glossary terms (CAR-DEF|Operator, CAR-DEF|Occurrence).

Merge rules (unchanged)

  1. Commit only your own files, straight to main. Run git pull --rebase before you push.
  2. Only the lead changes the contract. New fields go in extra.
  3. Every module runs on the mock data alone, and on data/articles.json once P1 has pushed it.
  4. Every cross-module import goes inside try/except. A broken module never crashes the demo.
  5. Feature freeze 15 minutes before the presentations. After that, only fixes.
